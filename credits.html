Авторство и источники

Последнее обновление: 16 ноября 2026

Информация об авторах, лицензиях и сторонних материалах.

О разработке

Сайт и связанные с ним приложения разработаны автором проекта самостоятельно с использованием современных инструментов разработки и программных помощников на основе искусственного интеллекта.

Использование сторонних инструментов и сервисов не подразумевает официального партнёрства, спонсорства или одобрения проекта их разработчиками.

Программное обеспечение

В проекте могут использоваться сторонние библиотеки, инструменты и компоненты, распространяемые на условиях собственных лицензий.

Сейчас на сайте нет сторонних библиотек и фреймворков: разметка, стили и скрипты написаны для этого проекта. Сайт собирается локальным скриптом на Python без внешних зависимостей.

Изображения и шрифты

Значки и оформление выполнены для проекта, сторонние изображения не используются. Шрифты берутся из операционной системы посетителя, отдельные шрифтовые лицензии к сайту не применяются.

Сторонние сервисы

Сайт размещён на GitHub Pages. Для обезличенной статистики посещаемости используется Cloudflare Web Analytics. Подробнее — в политике конфиденциальности.

Код проекта

Исходный код распространяется по лицензии MIT. Условия — на странице «Лицензия».
